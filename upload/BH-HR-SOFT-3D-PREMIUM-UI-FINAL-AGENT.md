# BH HR — FINAL VISUAL UI DIRECTION
## Premium Soft 3D / Neumorphic Editorial HR Interface

**Purpose:** Agent-ready UI implementation instruction  
**Product:** BH HR  
**Company:** Beyond Headlines  
**Scope:** Visual/UI redesign of the existing application only

---

# 1. DESIGN INTENT

Use the attached reference image as the **visual feel target**.

The target is NOT a normal admin dashboard.

The BH HR interface should feel:

- Premium
- Soft
- Elegant
- Futuristic
- Calm
- Tactile
- Editorial
- High-end SaaS
- 3D/neumorphic
- Visually layered

The reference combines:

```text
Lavender / purple atmosphere
+
Soft cream surfaces
+
Pastel pink
+
Warm orange
+
Purple accents
+
Soft 3D depth
+
Floating rounded cards
+
Large whitespace
+
Subtle gradients
+
Soft shadows
```

Translate this visual language into an **enterprise HR application**.

Do NOT copy the reference's sample text, numbers, finance concepts, illustrations, or fake product branding.

---

# 2. VERY IMPORTANT — PRESERVE THE EXISTING PRODUCT

This is a visual redesign.

Do NOT rebuild the product architecture.

Do NOT remove existing functionality.

Do NOT change:

- Database
- APIs
- Authentication
- Authorization
- Payroll calculations
- Attendance calculations
- Leave rules
- Document generation
- Email workflows
- Existing routes
- Existing HR business logic
- Existing permissions

The existing BH HR application remains the product.

The supplied image defines the **visual language only**.

# 6. THE MOST IMPORTANT VISUAL RULE

### Soft does NOT mean low contrast.

The reference image is soft, but its major labels and values remain readable.

BH HR must have:

```text
Clear title
Clear navigation
Clear KPI
Clear button
Clear table
Clear status
```

Avoid:

```text
light beige text
+
cream background
```

That was one of the problems in the previous BH HR UI.
